# CONVERT — универсальный Telegram-конвертер

Python **3.12**, aiogram 3, SQLite. Русский интерфейс с Inline-кнопками: «Конвертировать», «Настройки», «Форматы», «История», «Помощь». Файлы обрабатываются локально на компьютере бота, а передача сообщений и вложений проходит через Telegram.

## Запуск в Windows 10 / 11

Откройте PowerShell в папке проекта. Установите Python 3.12 с [python.org](https://www.python.org/downloads/windows/) или командой:

```powershell
winget install --exact --id Python.Python.3.12
```

`winget install` устанавливает программу, `--exact` требует точного совпадения идентификатора, `--id` задаёт пакет. После установки заново откройте PowerShell.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Первая команда создаёт отдельное окружение `.venv` на Python 3.12. `-m` запускает Python-модуль; `pip install -r` устанавливает пакеты из файла. `Copy-Item` создаёт настройки; выполняйте её только если `.env` ещё нет, чтобы не перезаписать токен.

Альтернатива: `powershell -ExecutionPolicy Bypass -File .\setup.ps1`. `-File` запускает скрипт, `-ExecutionPolicy Bypass` разрешает его выполнение только для этого процесса. Скрипт создаёт окружение, устанавливает пакеты и запускает проверку изображения; существующий `.env` сохраняется.

Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`. Откройте `.env` и замените значение `BOT_TOKEN` выданным токеном. Храните его в секрете.

```powershell
.\.venv\Scripts\python.exe bot.py
```

Команда запускает long polling. Оставьте терминал открытым; `Ctrl+C` завершает работу и отменяет задания. Активация окружения не требуется. Можно запускать `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Для одной базы данных запускайте **один экземпляр** бота. В личном чате нажмите `/start` и отправьте файл.

## Внешние конвертеры

### LibreOffice — документы, таблицы, презентации

```powershell
winget install --exact --id TheDocumentFoundation.LibreOffice
```

Или скачайте установщик с [официального сайта LibreOffice](https://www.libreoffice.org/download/download-libreoffice/). Установка может запросить права администратора. Обычно путь определяется автоматически. Для другой папки задайте в `.env`:

```dotenv
LIBREOFFICE_PATH=C:\Program Files\LibreOffice\program\soffice.com
```

### FFmpeg — аудио и видео

Пакет `imageio-ffmpeg` из requirements поставляет готовый FFmpeg для Windows. Если он недоступен или нужен системный FFmpeg:

```powershell
winget install --exact --id Gyan.FFmpeg
```

После установки перезапустите терминал, либо задайте полный путь к `ffmpeg.exe` в `FFMPEG_PATH`. Ссылки на Windows-сборки есть на [ffmpeg.org](https://ffmpeg.org/download.html#build-windows). Сборка должна включать libx264, libvpx-vp9, libopus, libvorbis, libmp3lame и AAC. FFprobe не требуется.

Если установлен ShareX с FFmpeg в `C:\Program Files\ShareX\ffmpeg.exe`, бот также найдёт его автоматически.

Если программы нет, бот продолжает работать: скрывает недоступные варианты и показывает состояние в «Форматах». Pillow и PDF-конвертер устанавливаются через requirements.

## Реальная матрица преобразований

| Вход | Выход | Движок |
|---|---|---|
| DOCX, DOC, TXT, RTF, ODT, HTML | Другие форматы этой строки, PDF | LibreOffice Writer |
| PDF с текстовым слоем | DOCX, TXT | pdf2docx / PyMuPDF |
| XLSX, XLS, CSV, ODS | Другие форматы этой строки, PDF | LibreOffice Calc |
| PPTX, PPT, ODP | Другие форматы этой строки, PDF | LibreOffice Impress |
| JPG, PNG, WEBP, BMP, TIFF | Другие форматы этой строки | Pillow |
| MP3, WAV, OGG, FLAC, M4A | Другие форматы этой строки | FFmpeg |
| MP4, MOV, MKV, WEBM, AVI | Другие видеоформаты этой строки; MP3, WAV, OGG, FLAC, M4A | FFmpeg |

Повторная конвертация в то же расширение не предлагается. `.jpeg`, `.tif`, `.htm` распознаются как псевдонимы. Перед показом кнопок отдельный процесс проверяет содержимое: Pillow распознаёт изображения, сигнатуры и структура контейнеров определяют PDF/Office, FFmpeg проверяет медиа и наличие дорожек. Ошибочное расширение бинарного файла исправляется по содержимому. TXT и CSV не имеют однозначной сигнатуры, поэтому для них используется расширение и проверка UTF-8; разделитель CSV — запятая. Неизвестные, повреждённые и защищённые файлы отклоняются с понятным сообщением.

Ограничения:

- PDF не превращается обратно в презентацию или таблицу. OCR не реализован: PDF без текстового слоя возвращает понятную ошибку. Парольные PDF не открываются. Сложная вёрстка, формулы и шрифты могут измениться; качество DOCX зависит от исходного PDF.
- CSV содержит только один лист, без формул/оформления; импорт и экспорт UTF-8, разделитель запятая. TXT и CSV нужно отправлять в UTF-8.
- HTML возвращается **ZIP-архивом**, содержащим HTML и экспортированные ресурсы. Входной HTML должен быть самостоятельным; ресурсы, отправленные отдельными файлами, не подхватываются.
- Для анимированных изображений и многостраничного TIFF используется первый кадр/страница. EXIF-ориентация применяется; метаданные изображения не копируются. Прозрачность при JPG/BMP заменяется белым фоном.
- Настройка изображений влияет на JPG/WEBP. Аудио: 128/192/320 кбит/с для форматов с потерями; WAV/FLAC без потерь кодирования. Увеличение качества не восстанавливает утерянные данные.
- Видео: компактно/баланс/лучшее — CRF 28/23/18; AVI использует qscale 8/5/2. Берутся первая видеодорожка и первая аудиодорожка, субтитры и прочие потоки не переносятся. Размеры округляются вниз до чётных. Для немого видео кнопки извлечения аудио скрыты. Обложка аудиофайла не считается видеодорожкой. Не все кодеки внутри поддерживаемых контейнеров доступны в любой сборке FFmpeg.

## Лимиты и обработка

Стандартный облачный [Telegram Bot API](https://core.telegram.org/bots/api#getfile) позволяет скачивать вложения до 20 МБ; бот принимает до 20 МиБ и отправляет результаты до 49 МиБ, оставляя запас к лимиту отправки. Настройки не позволяют превысить эти пределы. Локальный Bot API в этом проекте не настраивается.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| BOT_TOKEN | — | Токен BotFather |
| LIBREOFFICE_PATH | авто | Полный путь к soffice.com / soffice.exe |
| FFMPEG_PATH | авто | Полный путь к ffmpeg.exe |
| MAX_FILE_MB | 20 | Максимальный вход, МиБ; можно уменьшить |
| MAX_OUTPUT_MB | 49 | Максимальный результат, МиБ; можно уменьшить |
| CONVERSION_TIMEOUT | 180 | Тайм-аут обработки в секундах, без ожидания очереди |
| MAX_CONCURRENT | 2 | Одновременно работающие конвертеры |
| MAX_PENDING | 8 | Максимум активных загрузок, проверок и конвертаций, включая очередь |
| FILE_TTL_SECONDS | 900 | Срок хранения загруженного файла до выбора формата |
| DATA_DIR | data | Папка SQLite и временных файлов, относительно проекта |

Проверка содержимого и конвертация запускаются в отдельных процессах: event loop не блокируется. Очередь ограничена; у пользователя одно активное задание. Загрузка останавливается по фактически полученным байтам при превышении лимита. Отмена и тайм-аут завершают дерево процессов (`taskkill /PID ... /T /F` на Windows: PID процесса, всё дерево, принудительно), после чего удаляется временная папка. После успеха, ошибки или отмены исходник и результат удаляются. Очистка просроченных загрузок выполняется раз в 30 секунд; оставшиеся после аварии папки `data/temp/job-*` удаляются при старте. Удаление ограничено папками заданий внутри `DATA_DIR/temp`; символические ссылки и junction пропускаются. Блокировка `data/bot.lock` не даёт запустить второй экземпляр с теми же данными. Главное меню не отменяет выполняющуюся задачу; используйте «Отмена» или `/cancel`.

`data/bot.sqlite3` хранит настройки отдельно для каждого Telegram user ID и до 100 записей истории на пользователя, меню показывает последние 10 (время UTC). Историю можно очистить кнопкой. Сами файлы в базе не хранятся. Токены, содержимое файлов и полные Telegram-ошибки в лог не выводятся. Не публикуйте `.env`, базу и временные папки.

Свежий профиль LibreOffice отключает макросы; FFmpeg ограничен локальными протоколами, число пикселей и распакованный размер Office ограничены. Это меры защиты, но процессы не являются полноценной песочницей. Для публичного сервиса запускайте под отдельной учётной записью без доступа к личным файлам, лучше в изолированной VM/контейнере, с обновлёнными конвертерами. Входные HTML/Office могут содержать внешние ссылки; ограничьте сетевой доступ процессов конвертеров средствами ОС.

## Проверки

Не требуют токена или соединения с Telegram:

```powershell
.\.venv\Scripts\python.exe check.py --smoke
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`check.py` импортирует зависимости, проверяет запуск внешних программ и выполняет PNG → JPG через настоящий отдельный процесс. Отсутствующая Python-зависимость или неработающий конвертер дают ненулевой код завершения. Флаг `--require-all` также требует наличия LibreOffice и FFmpeg.

Для полной проверки всех **61 офисных преобразований** установите дополнительные библиотеки создания тестовых XLSX/PPTX:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m ruff check .
```

Тесты проверяют реальные результаты PDF, изображений и FFmpeg, кириллицу TXT/CSV, структуру Office, SQLite, меню, сценарий загрузка → выбор → отправка → очистка с имитацией ответов Telegram, параллельных пользователей, отмену, тайм-аут, лимиты и защиту удаления. Отсутствующие внешние движки и дополнительные библиотеки тестовых данных отмечаются как пропуск. Офисная матрица занимает несколько минут. Текущий результат проверки записан в `VALIDATION.md`.

Для проверки Telegram: `/start` → PNG → JPG → скачайте результат; измените качество в настройках; отправьте видео и отмените; проверьте историю; отправьте неподдерживаемый и слишком большой файл. Два пользователя могут одновременно пользоваться меню и конвертацией. Без настоящего BOT_TOKEN отправку и получение сообщений проверить нельзя.

## Структура

`bot.py` — меню, приём файлов, очередь и отмена; `formats.py` — допустимые пары; `config.py` — окружение и поиск программ; `database.py` — SQLite; `converter.py` — запуск/остановка процессов; `inspection.py` — определение содержимого и дорожек; `worker.py` — конвертеры; `check.py` и `tests/` — проверки. Сложных фреймворков и брокеров задач нет.

## Если что-то не работает

- «Заполните BOT_TOKEN»: скопируйте `.env.example` в `.env` и укажите токен.
- Ошибка Telegram: проверьте токен, сеть, VPN и отсутствие второго процесса с тем же токеном.
- Нет кнопок для Office: установите LibreOffice, проверьте путь в `.env`, перезапустите бота.
- `pip` не скачивает пакеты: проверьте доступ к pypi.org и files.pythonhosted.org. Сетевые ограничения нельзя исправить кодом проекта.
- Тайм-аут: уменьшите файл или увеличьте CONVERSION_TIMEOUT; для слабого ПК поставьте MAX_CONCURRENT=1.
- Результат слишком большой: понизьте качество либо выберите формат со сжатием. Бот не отправляет усечённые результаты.
- После изменения `.env` требуется перезапуск.
